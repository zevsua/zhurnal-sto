# Журнал СТО — Android-програма

Працює повністю без інтернету. Усі записи зберігаються в телефоні.
Резервна копія: кнопка ⋮ угорі → «Зберегти копію в файл» (записи без фото).
Фото до авто: у вікні запису кнопки «Камера» і «Галерея».

## Як отримати APK

### Варіант 1 — через GitHub (нічого не треба встановлювати)
1. Зареєструйтесь на https://github.com і натисніть **New repository**.
   Назва — наприклад `zhurnal-sto`, можна поставити **Private**. Натисніть **Create repository**.
2. На сторінці репозиторію натисніть **uploading an existing file**.
3. Розпакуйте архів і перетягніть у вікно браузера **весь вміст папки ZhurnalSTO**
   (папки `.github`, `app`, `gradle` і всі файли). Унизу натисніть **Commit changes**.
4. Відкрийте вкладку **Actions**. Збірка запуститься сама й триватиме 3–5 хвилин
   (якщо GitHub попросить увімкнути Actions — увімкніть).
5. Готовий файл буде праворуч у розділі **Releases** → **Zhurnal-STO.apk**.
   Відкрийте цю сторінку на телефоні й завантажте APK.

### Варіант 2 — Android Studio на комп'ютері
1. Встановіть Android Studio: https://developer.android.com/studio
2. **File → Open** → виберіть розпаковану папку `ZhurnalSTO`.
   Зачекайте, поки внизу закінчиться синхронізація (перший раз Studio сама докачає потрібні компоненти).
3. **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
4. У повідомленні натисніть **locate**: файл `app-debug.apk` лежить у `app/build/outputs/apk/debug/`.

## Встановлення на телефон
Відкрийте APK на телефоні. Якщо Android попередить про невідоме джерело, дозвольте встановлення
для файлового менеджера чи браузера, з якого відкриваєте.

Нові версії ставляться поверх старої, і записи при цьому зберігаються
(усі збірки підписані одним ключем `app/release.jks`, тому не видаляйте цей файл).
Записи пропадуть, тільки якщо видалити програму або очистити її дані. Тому час від часу робіть резервну копію.
